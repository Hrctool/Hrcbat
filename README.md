## Description
HRC Tools delivers deep system cleanup, privacy control, UI tweaks, network optimization, and a 3200+ app installer. Features auto UAC elevation, bilingual (EN/CN) interface, real progress bar (PowerShell), and modular loading.

**Requirements:** Windows 10/11, Administrator rights, PowerShell (optional).

## Main Menu Highlights
- Clean & Optimize | Privacy & Security | UI & Personalization
- Network & Services | Hardware & System | Backup & Activation
- Software Center | Advanced Toolbox (Game, Battery, Office, etc.)
